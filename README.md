# KotonoEngine

## Build
### Visual Studio 17
- To build the solution for Visual Studio 17, execute *[KotonoTestApplication/build_vs17.sh](KotonoTestApplication/build_vs17.sh)*.

### Other IDE
- To build the solution for other IDEs, navigate to *[KotonoTestApplication/](KotonoTestApplication/)* and run CMake for your IDE.

### Note
- All generated build files will be located in *KotonoTestApplication/build/*.

## Shader Compilation
To enable automatic shader compilation, make sure you have the [Vulkan SDK](https://vulkan.lunarg.com/sdk/home) and that its bin folder is added to your system’s PATH environment variable.
